Forecasts each GTA VI PS5 trophy's Exophase earn rate at the target as five quantiles, by splitting every rate into its earner count and the tracked-player count, trending both against log time since release, and blending that with a direct logit-rate trend.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
